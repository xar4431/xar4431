## Proyecto destacado

### [CODICE](https://codicecuba.org) — Cuba · OSINT sobre Delincuentes Informáticos y Campañas de Estafa

Plataforma comunitaria para documentar y analizar phishing, suplantaciones y estafas digitales en Cuba, con un panel de investigación para el equipo de moderación.

| Área | Qué hace |
| :-- | :-- |
| **Análisis** | Motor que relaciona casos por indicadores compartidos (números, enlaces, perfiles, cuentas de cobro) y sugiere campañas |
| **Visualización** | Grafo de relaciones y mapa interactivo en SVG |
| **Moderación** | Roles y permisos, cola de revisión, expedientes, cadena de custodia y veredictos |
| **Seguridad** | 2FA (TOTP), hash Argon2, detección y bloqueo automático de ataques, límites de abuso |
| **Infraestructura** | Servidor propio 24/7, respaldos cifrados diarios y app de escritorio para monitorizarlo |
| **Interfaz** | Responsive, modo oscuro/claro e interfaz bilingüe (ES/EN) |
